Backup & data

Your data is saved in this browser on this device. Export a backup at least weekly; import merges backups from another device without deleting records. To use the same live data on iPhone and Mac, this app must be hosted and connected to shared storage; this starter version does not sync automatically.

Use on iPhone

For an app-like icon on your iPhone, this project must first be published at a secure HTTPS address.

  1. Open the published app in Safari.
  2. Tap the Share button.
  3. Choose Add to Home Screen.
  4. Open it from the new icon.

Important: this starter saves data only in the current browser. It does not sync with your Mac or another device. Use Export backup before switching devices. Shared automatic sync needs hosting plus a shared database.
